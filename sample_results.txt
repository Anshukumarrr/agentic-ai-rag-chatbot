Q4. What is a multi-agent system and how does it work?
confidence: 0.5291   grounded: True
------------------------------------------------------------------------------
A multi‑agent system (MAS) is an agentic architecture that contains multiple agents—at least one worker and one utility agent—working toward clear goals (excerpt 2). These agents can operate independently, allowing dynamic task allocation and parallel processing, which is especially useful for complex, dynamic tasks (excerpt 1). MAS can be organized hierarchically, where agents act within a specific domain, or in a peer‑to‑peer fashion, enabling any agent to communicate with any other (excerpt 2). Communication is essential; agents exchange information, negotiate tasks, and collaborate using well‑defined protocols and languages to avoid misunderstandings (excerpt 4). Through this coordinated interaction, MAS verify work, adapt in real time, and improve task outcomes (excerpt 1).
